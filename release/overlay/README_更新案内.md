# v1.0.0への更新

現在のアプリで「状態・設定」→「更新を確認して適用」を押し、内容を確認して更新してください。配布元は登録済みの `takad55/LocalStudyAI-updates` です。ZIPの展開、フォルダの選び直し、CLIでの公開操作は不要です。

更新後は左メニューに「まとめて整理」「資料検索・要約」が表示されます。起動は従来のデスクトップショートカットのままです。既存の操作履歴、設定、Ollamaモデルは引き継ぎます。

## 通常の使い方

- PC整理：対象フォルダを選ぶ → 依頼を入力して調査 → 候補を選び「整理案を確認する」 → 内容を確認して承認。
- 大学資料：対象フォルダを選ぶ → 索引を作成・更新 → 原文を検索、出典付き回答、または複数資料を選んで一括要約。
- ChatGPT相談：候補を選ぶ → 相談文を作る → 個人情報を確認してコピー → 回答のJSONを取り込み、提案を再確認。

## 問題が起きた場合

「状態・設定」の「前の版に戻す」でプログラムを切り戻せます。切り戻しは実ファイル整理を元に戻す操作ではありません。ファイル移動は操作履歴から、ごみ箱への移動はWindowsのごみ箱から復元します。

バージョン表示が変わらない場合は、アプリを終了して今までの固定インストール用ショートカットから起動してください。ブラウザのタブを閉じるだけではサーバーが終了しません。

認証情報、講義資料、個人の操作履歴は更新ファイルに含みません。更新パッケージにはソースコード・既定設定・生成サンプル・自動テストだけを含めています。
