# LocalStudy AI v1.0.0

Windowsのファイル整理と大学資料の読解を、ブラウザの一つの窓口で扱うローカルアプリです。既存のOllama・モデル・Python環境・履歴を維持します。

## 更新と起動

既存アプリの「状態・設定」→「更新を確認して適用」でv1.0.0を取得してください。登録済みの公開GitHub Releasesからアプリコードだけをダウンロードします。資料をGitHubに送る処理はありません。通常の起動は今までのデスクトップショートカットです。

## 日常の操作

### PCを整理する
1. 「まとめて整理」で対象フォルダを選択します。選択したフォルダとその配下だけが対象です。
2. 「このフォルダを整理して」「大学資料を科目ごとに分類して」「不要候補を調べて」「重複を整理して」などを入力するか、画面の選択肢を押して調査します。
3. 候補の理由と移動先を確認します。移動先は画面で変更できます。未使用と断定できないファイルのごみ箱候補は初期状態で未選択です。
4. 対象を選び「整理案を確認する」へ進みます。従来の実行確認で承認するまで、元ファイルは変更しません。
5. 結果は「操作履歴」へ記録します。移動・名前変更は変更検証後に取り消せます。ごみ箱への移動はWindowsのごみ箱から復元してください。

自然言語入力は対応する調査機能への入口です。任意のWindows操作やコマンドの実行はしません。フォルダの外へ移動する機能はありません。実ファイル操作の上限はフォルダ作成を含め200操作です。

### 大学資料を探して理解する
1. 「資料検索・要約」で資料のあるフォルダを選び「索引を作成・更新」を実行します。
2. 用語を入力して「原文を検索」。原文だけならOllamaを起動する必要はありません。
3. 「出典付きで回答」は検索結果をローカルAIへ渡します。PDFはp.番号、Wordは段落、PowerPointはスライド、Excelはシート・行、テキストは行番号を表示します。
4. 登録済み資料を選び「一括要約」で複数資料をまとめます。結果をコピー・Markdown保存できます。

検索はUnicode正規化・日本語の部分文字列を使うローカル索引検索です。埋め込みによる意味検索ではありません。ファイルが変更・移動・削除されたら古い検索結果を使わず、索引の更新を促します。

### ChatGPTに相談する
1. 整理候補から相談対象を1〜30件選択します。
2. 「相談文を作る」で情報を生成します。本文の一部を含めるかは任意です。
3. 氏名・生徒情報・機密情報を確認してからコピーし、ChatGPTに貼り付けます。自動送信・有料APIはありません。
4. 回答のJSON部分を「回答のJSONを取り込む」に貼り付けると、同じ調査の既存候補に提案を反映します。すべて未選択に戻り、再承認が必要です。

## 安全性と制限

- 移動・削除の判断をモデルだけに任せません。対象範囲、元ファイルのハッシュ、同名衝突、保持対象を実行前に再検証します。無承認の実行と永久削除はありません。
- 「不要候補」は旧インストーラー・アーカイブ・ダウンロード途中ファイル等の条件判定です。古さは未使用の証明ではなく、削除の初期選択には使いません。
- 重複整理は内容完全一致を使います。統合画面は1件を保持します。原本を含む全件整理は従来の専用画面にある追加確認付きモードです。
- 一般分類は対象直下の種類別整理、科目を確定できる大学資料は配下も含め科目・講義回・資料区分で提案します。アプリ・開発環境内部は避けます。
- 資料1件50MB、抽出は160ページ相当・40万文字まで。図・画像の意味、複雑な数式、画像PDFのOCR、暗号化PDFは未対応です。Excelを再計算しません。
- 一括要約は1回12資料、1資料は設定値（標準24,000字）、全体100,000字までです。読んだ範囲と未要約部分を表示します。抽出制限があるため「全文を完全に理解した」とは扱いません。
- 出典IDの存在は機械確認しますが、AIの説明が原文の意味と一致するかまでは保証しません。重要な式や提出用の解答は原資料と照合してください。
- 調査中は進捗を表示し、中断できます。Ollamaの応答待ちは応答または通信タイムアウト後に中断します。実ファイル変更中は中断しないでください。
- 索引と相談文はPC内のデータフォルダに保存します。秘密情報の自動マスクは補助であり、全個人情報を検知しません。
- ローカルサーバーは127.0.0.1限定、Origin・Host・トークンを検証します。ファイル内容やAI応答のHTMLはエスケープします。
- 公開GitHubにはアプリコード・テスト用生成データだけを含めます。更新のSHA-256は破損検出であり、配布者が乗っ取られた場合の独立署名保証ではありません。GitHubアカウントの保護は別途必要です。
- kibacoの自動ログイン・資料取得、無確認の自律削除、ChatGPTへの自動送信は今回の対象外です。

## データ・復旧

固定保存先は `%LOCALAPPDATA%\LocalStudyAI`。プログラムは `releases`、設定と資料索引・履歴は `data` に分離します。前版への切り戻しは「状態・設定」から行えます。切り戻してもv1専用の索引ファイルは残ります。旧インストールフォルダを参照する過去の操作履歴がある場合は、そのフォルダを削除しないでください。

「前回の調査」は直近の候補を読み込みます。実行前の再検証で変更済み資料は停止します。長時間処理中のブラウザ再読み込みでも、サーバーが起動している間は進捗を再取得します。アプリ終了中に処理を続ける機能はありません。
